# Ayush SSC Quiz Hub

Complete static website structure based on the uploaded SSC Complete Super Syllabus PDF.

Hierarchy:
Home → Subject → Section → Topic → Quiz

Every topic has its own folder with an `index.html` placeholder. Upload your actual quiz HTML into that topic folder.

Example:
`General Studies/Geography/solar-system/quiz-1.html`

The syllabus list is source-derived from the uploaded PDF; no extra syllabus topics were invented.

GitHub Pages does not require a 30-day trial for this static site. If you saw a 30-day message, that was separate from this website/repository.
